# Usage and settings

## Sub-features

- View Cost, Tokens, and Limits.
- Change notification and hover-preview settings.
- Inspect connection and reconnect controls.

## How to get to it (user POV)

Open the paired Bar panel, choose Usage or Settings, and return to the thread list.

## Driving it with Computer Use

Capture each screen and record whether values are live, cached, partial, or unavailable. Verify that Settings can return to the thread list without losing the connection.

## Gotchas

The Usage screen can show cached local data while the live connection is down. When a remote environment is selected, local Usage and Limits must be cleared and marked unavailable until a remote usage contract exists.
