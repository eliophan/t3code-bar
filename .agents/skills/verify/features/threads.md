# Threads

## Sub-features

- Render the live thread list.
- Show offline or cached state honestly.
- Open a thread in T3 Code from the Bar.

## How to get to it (user POV)

Pair the Bar, open the menu bar panel, and select a visible thread.

## Driving it with Computer Use

Capture the panel before and after pairing. Open one thread and verify that T3 Code receives the navigation request. If the panel says offline, record the banner and do not treat cached rows as live proof. For a linked environment, select it first and verify its shell snapshot is live before opening a row.

## Gotchas

The Bar reads T3 Code projections and caches. Remote thread IDs are scoped by environment; identical IDs on two machines must remain separate.
